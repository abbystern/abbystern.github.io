# Change 2: Add résumé access and improve professional navigation

## Goal

Make it easier for a visitor to move from my portfolio introduction to more detailed information about my professional experience and to contact me.

## Planned changes

- Add my current résumé PDF to the site's assets.
- Add a clear “View Résumé” link or button in an appropriate location on the Home page.
- Improve the Home page's calls to action so visitors can easily move to my Work Experience, résumé, or Contact page.
- If appropriate, also make the résumé accessible from the Work Experience page without making the navigation cluttered.
- Make résumé links open the PDF reliably on GitHub Pages.
- Preserve accessibility and mobile responsiveness.
- Do not redesign the overall visual style of the site. A broader visual redesign will happen separately.
- Do not alter or invent any résumé content, employers, achievements, projects, or metrics.

## Why

The portfolio currently explains my background and experience, but visitors do not have an obvious way to access my full résumé. This improvement creates a clearer professional user journey and makes the site more useful as a portfolio.
